# Recurso 12: Demo y cierre

## Secuencia de demostración

1. Ejecuta un turno con un comando natural y señala que la respuesta procede de un evento validado.
2. Explora una dirección no conocida y muestra que aparece una localización coherente y persistida.
3. Abre el editor, muestra una validación o una propuesta pendiente y publica sólo tras una acción explícita.
4. Si es posible, provoca un fallback visual o de IA y enseña que el juego sigue funcionando.

## Mensaje de cierre

"No hemos delegado el juego en un modelo. Hemos construido una arquitectura donde la IA aporta lenguaje y presentación, mientras la realidad del juego sigue siendo verificable, observable y reemplazable."

## Plan de contingencia

Usa capturas preparadas para cada paso de la demo y conserva una partida válida y un borrador válido. Si Azure AI o la generación visual no están disponibles, demuestra el fallback y explica que ese es precisamente el comportamiento esperado.
