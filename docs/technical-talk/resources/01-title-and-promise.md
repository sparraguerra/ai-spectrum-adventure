# Recurso 01: Título y promesa

## Texto para la diapositiva

**AI Spectrum Adventure**

Una aventura conversacional retro donde la IA interpreta y narra, pero las reglas siguen siendo código determinista.

## Visual

Usa una captura de la pantalla de juego con una localización, inventario y el historial de un turno. La captura debe mostrar el producto real, no una imagen conceptual. Deja espacio para el título sobre la imagen.

## Mensaje oral

"La pregunta no es si un modelo puede contar una aventura. Puede hacerlo. La pregunta es cómo permitimos lenguaje natural sin entregar al modelo la realidad del juego. Esta charla explica esa frontera."
