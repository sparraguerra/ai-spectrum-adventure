# Recurso 06: Responsabilidades de IA

| Rol | Puede hacer | No puede hacer |
| --- | --- | --- |
| Intérprete | Proponer intención estructurada | Cambiar inventario o resolver un puzle |
| Narrador | Describir hechos confirmados | Inventar objetos, salidas o consecuencias |
| NPC | Responder dentro de su contexto y conocimiento | Revelar lore no permitido o mutar el mundo |
| Director visual | Proponer o generar una imagen opcional | Definir contenido autoritativo |
| Propuesta de autoría | Sugerir un parche revisable | Guardar, publicar o aceptar el borrador |

## Mensaje oral

"Cada uso de IA tiene un contrato estrecho. Cuanto más cerca está del estado, menos poder tiene. Este reparto limita alucinaciones, permite fallbacks y conserva pruebas deterministas."
